# 제자리 뛰기 훈련 (jump)

> 출처: [제자리 뛰기 훈련 (jump)](https://www.youtube.com/watch?v=J2aBQ0zjwWY)
> 채널: 기록아빠 (퀘이커 앵무새 끼룩이)

<iframe width="100%" height="315" src="https://www.youtube.com/embed/J2aBQ0zjwWY" frameborder="0" allowfullscreen></iframe>


## 요약

앵무새가 바닥에서 제자리 점프를 하는 훈련이다. 날개 훈련이 선행되어야 하며, 날개짓을 하다가 자연스럽게 바닥에서 살짝 뜨는 동작을 강화시켜 점프로 발전시킨다. "제자리 뛰기"라는 새 명령어를 기존 "날개" 명령어에 점진적으로 연결하는 방식이다.

## 훈련 방법

1. **날개 훈련 완성**: 먼저 날개 훈련을 완벽하게 완성시킨다.
2. **바닥에서 날개 반복**: 바닥에서 날개 동작이 잘 될 때까지 계속 반복한다.
3. **새 명령어 연결**: "제자리 뛰기" + "날개"를 함께 말한다. 반복하다 보면 "제자리 뛰기"만 듣고도 날개를 하기 시작한다. 그때부터는 "제자리 뛰기"만 말한다.
4. **뜨는 동작 강화**: 날개짓을 하다 보면 바닥에서 살짝 다리가 뜨는 경우가 생긴다. 많이 뜰 때만 큰 칭찬과 해바라기씨 보상을 해주면, 앵무새가 "좀 세게 해서 떠야 먹이가 나오는구나"를 인지하게 된다.

## 주의사항

- 날개 훈련이 반드시 선행되어야 한다
- 날개짓만 하고 뜨지 못하는 경우, 많이 뜰 때만 보상을 줘서 점프를 유도할 것
- 절대 포기하지 말고 천천히 할 것 — 앵무새가 주인의 마음을 알아주고 따라오면 배우는 속도가 빨라진다

## 난이도

보통
