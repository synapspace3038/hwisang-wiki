# 하이킥 훈련 (high kick)

> 출처: [하이킥 훈련 (high kick)](https://www.youtube.com/watch?v=aAJZ5OJQYZA)
> 채널: 기록아빠 (퀘이커 앵무새 끼룩이)

## 요약

"하이킥" 하면 앵무새가 발을 높이 올리는 훈련이다. 왼발/오른발 훈련(악수 심화과정)이 선행되어야 하며, 발을 올리는 높이를 점점 올려가는 방식으로 진행한다. 포즈 훈련을 활용해 발을 올린 상태에서 카운트하며 유지하게 할 수도 있다.

## 훈련 방법

1. **왼발/오른발 훈련 선행**: 악수 심화과정(왼발, 오른발)이 먼저 되어 있어야 한다.
2. **낮은 위치부터 시작**: "하이킥" 하면서 발을 올리게 하되, 처음에는 낮은 위치에서 시작한다.
3. **점점 높이 올리기**: 발을 올리는 위치를 점점 높여간다. 손가락 등을 이용해 원하는 높이까지 유도.
4. **포즈 훈련 연결**: 발을 올린 상태에서 "하나, 둘, 셋" 카운트를 세며 유지하게 하는 것도 가능.

## 주의사항

- 한 번에 진도를 너무 빼려고 하지 말 것 — 낮은 단계에서 점점 원하는 위치까지 올릴 것
- 왼발/오른발 구분이 되어야 하이킥도 깔끔하게 가능
- 킥복싱처럼 응용할 수도 있다
