# 고리 가져오기 훈련 (putting it back)

> 출처: [고리 가져오기 훈련 (putting it back)](https://www.youtube.com/watch?v=D_bX1_TJzA8)
> 채널: 기록아빠 (퀘이커 앵무새 끼룩이)

<iframe width="100%" height="315" src="https://www.youtube.com/embed/D_bX1_TJzA8" frameborder="0" allowfullscreen></iframe>


## 요약

앵무새가 고리를 부리로 물어서 집사의 손으로 가져다 주는 훈련이다. 고리걸기 훈련의 선행 단계이며, 훈련 도구에 대한 적응이 먼저 되어 있어야 한다. 고리를 무는 것부터 시작해서, 물고 들어올리고, 손에 떨어뜨리는 과정을 단계적으로 진행한다.

## 훈련 방법

1. **훈련 도구 적응**: 고리 등 훈련 도구를 무서워하지 않도록 먼저 적응시킨다.
2. **고리 물기 유도**: 고리를 앵무새 부리 가까이 갖다 대고, 앵무새가 물도록 유도한다. 위아래로 흔들어주면 관심을 가진다.
3. **물고 들어올리기**: 고리를 문 상태에서 살짝 올리는 동작이 나오면, 클리커 클릭 + 보상. "하나 둘 셋" 카운트 훈련이 되어 있으면 더 편하게 진행 가능.
4. **손에 떨어뜨리기**: 고리를 물고 올린 상태에서, 손을 앞에 두고 손 위에 떨어뜨리게 유도한다. 손에 떨어뜨렸을 때 보상.
5. **바닥에서 주워 가져오기**: 고리를 바닥에 놓고, 앵무새가 스스로 물어서 들고 손까지 가져오게 거리를 점점 늘린다.

## 주의사항

- 앵무새가 물건 무는 것을 싫어하는 경우가 있다 — 억지로 시키지 말고, 놀이하듯 관심을 유도할 것
- 포즈 훈련(하나 둘 셋 카운트)이 되어 있으면 훨씬 진행이 수월하다
- 이 훈련을 완성하면 고리걸기 훈련으로 자연스럽게 이어갈 수 있다
- 훈련 도구를 무서워하면 먼저 적응 훈련부터 할 것
