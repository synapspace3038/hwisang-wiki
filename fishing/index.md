## 시즌 캘린더

| 시기 | 추천 활동 | 장소 |
|------|-----------|------|
| 3~4월 | 양양 황어 잡기, 봄 도다리 | 양양 남대천, 속초 |
| 4~5월 | 꺽지 구멍치기 시즌 시작 | 가평/양평 계곡 |
| 5~9월 | 계곡 구멍치기 본시즌 | 가평/양평 계곡 |
| 6~8월 | 해루질, 테트라포트 탐험, 수중낚시 | 동해안 |
| 7~10월 | 오징어 에깅 | 속초 대포항 |
| 9~11월 | 감성돔, 볼락 | 동해안 방파제 |
| 10~12월 | 주꾸미 에기 낚시 | 동해안 (또는 서해안) |
| 11~1월 | 도루묵 통발, 임연수 | 속초/양양/고성 |
| 12~5월 | 피문어 해루질 | 동해안 방파제 |

## 하남/미사에서 가는 법

- **가평 계곡** (구멍치기 낚시): 미사대로 → 경춘대로 → 가평 (약 1시간~1시간 30분)
- **양평 계곡**: 중부고속도로/중앙고속도로 → 양평 (약 40분~1시간)
- **속초/양양** (바다 낚시): 서울양양고속도로 → 속초/양양 (약 2시간 30분)
- **인천/안산** (서해 주꾸미): 수도권 서쪽 (약 1시간~1시간 30분)
